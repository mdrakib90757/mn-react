# Meeting Notes AI (মিটিং নোটস এআই)

একটি প্রিমিয়াম Chrome Extension (Manifest V3) যা Google Meet, Zoom Web, বা Microsoft Teams-এর লাইভ মিটিং শুনে রিয়েল-টাইমে বাংলা ও ইংরেজি ট্রান্সক্রিপ্ট তৈরি করে, প্রাসঙ্গিক প্রশ্ন জেনারেট করে এবং নির্দিষ্ট বিষয়ের ওপর স্বয়ংক্রিয় নোট সংগ্রহ করে।

---

## 🏗 সিস্টেম আর্কিটেকচার

1. **অডিও ক্যাপচার (Chrome Extension):**
   - `chrome.tabCapture` দিয়ে মিটিং ট্যাবের আসল অডিও এবং `getUserMedia` দিয়ে ব্যবহারকারীর মাইক্রোফোন ক্যাপচার করা হয়।
   - অফস্ক্রিন ডকুমেন্টে (`offscreen.html`) Web Audio API দ্বারা উভয় অডিও মিক্স করা হয় এবং ব্যবহারকারী যাতে মিটিং শুনতে পান সেজন্য ট্যাবের অডিও স্পিকারেও ফরোয়ার্ড থাকে।
   - `pcm-worklet.js` এর মাধ্যমে অডিওকে **16 kHz 16-bit Linear PCM** ফরম্যাটে কনভার্ট করে প্রতি ১০০ms অন্তর WebSockets দিয়ে ব্যাকএন্ডে পাঠানো হয়।

2. **স্ট্রিমিং ট্রান্সক্রিপশন (Backend STT):**
   - Node.js ESM ব্যাকএন্ড (`ws://localhost:8080`)
   - Deepgram Nova-3 (`language: bn`) দিয়ে হাই-অ্যাকুরেসি লাইভ বাংলা স্ট্রিমিং স্পিচ-টু-টেক্সট।

3. **লাইভ মিটিং বিশ্লেষণ (Backend LLM):**
   - Google Gemini (`gemini-3.8-flash`) দিয়ে মিটিং চলাকালীন রিয়েল-টাইম প্রশ্নোত্তর (স্পষ্টীকরণ, গভীরে, ঝুঁকি, অ্যাকশন) ও ট্র্যাক করা বিষয়ের ওপর সংক্ষিপ্ত নোট তৈরি।

4. **ইউজার ইন্টারফেস (React 18 Side Panel):**
   - প্রিমিয়াম মডার্ন ডিজাইন (Linear/Granola অনুপ্রাণিত)।
   - Inter Variable ও Noto Sans Bengali Variable ফন্ট সহ ডার্ক/লাইট মোড সমর্থন।

---

## 📋 প্রাক-প্রয়োজনীয়তা (Prerequisites)

- **Node.js**: v18.0.0 বা তার বেশি
- **Google Chrome**: v116 বা তার বেশি
- **Deepgram API Key**: [Deepgram Console](https://console.deepgram.com/) থেকে সংগ্রহ করুন।
- **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/) থেকে সংগ্রহ করুন।

## 🚀 সেটআপ ও ইনস্টলেশন নির্দেশিকা

### ধাপ ১: ডিপেন্ডেন্সি ইনস্টল করুন

```powershell
# রুট ফোল্ডারে React/Vite ডিপেন্ডেন্সি ইনস্টল
cd D:\mn-react
npm install

# ব্যাকএন্ড ডিপেন্ডেন্সি ইনস্টল
cd backend
npm install
```

### ধাপ ২: ব্যাকএন্ড কনফিগারেশন (`backend/.env`)

`backend/.env` ফাইলে আপনার এপিআই কি-সমূহ সেট করুন:

```env
PORT=8080

# Deepgram STT Configuration (Bengali)
DEEPGRAM_API_KEY=your_deepgram_api_key_here
DG_MODEL=nova-3
DG_LANGUAGE=bn
DG_SAMPLE_RATE=16000
DG_ENCODING=linear16

# LLM Configuration (Gemini)
LLM_PROVIDER=gemini
LLM_API_KEY=your_gemini_api_key_here
LLM_MODEL=gemini-3.8-flash
```

### ধাপ ৩: এক্সটেনশন বিল্ড করুন

```powershell
cd D:\mn-react
npm run build
```
এটি `D:\mn-react\dist` ফোল্ডারে এক্সটেনশনের সমস্ত ফাইল প্রস্তুত করবে।

### ধাপ ৪: গুগল ক্রোমে লোড করুন

1. ক্রোমে গিয়ে অ্যাড্রেস বারে যান: `chrome://extensions`
2. উপরে ডানদিকের **Developer mode** টগলটি অন করুন।
3. **Load unpacked** বাটনে ক্লিক করে `D:\mn-react\dist` ফোল্ডারটি নির্বাচন করুন।

## 🎙 ব্যবহার পদ্ধতি (How to Use)

1. **সার্ভার চালু করুন:**
   একটি টার্মিনালে ব্যাকএন্ড রান করুন:
   ```powershell
   cd D:\mn-react\backend
   node server.js
   ```

2. **মিটিং শুরু করুন:**
   যেকোনো ট্যাবে Google Meet, Zoom Web, অথবা একটি বাংলা ইউটিউব ভিডিও ওপেন করুন।

3. **সাইড প্যানেল ওপেন করুন:**
   ক্রোমের এক্সটেনশন আইকন থেকে **Meeting Notes AI** ওপেন করুন।

4. **"শুরু করুন" বাটনে চাপুন:**
   - এক্সটেনশনটি স্বয়ংক্রিয়ভাবে ট্যাবের সাউন্ড ও আপনার মাইক্রোফোন ক্যাপচার করে ব্যাকএন্ডে পাঠাবে।
   - স্পিকারের কথা বলার সাথে সাথে লাইভ বাংলা ট্রান্সক্রিপ্ট দেখতে পাবেন।
   - কথোপকথনের ওপর ভিত্তি করে এআই স্বয়ংক্রিয়ভাবে প্রশ্ন ও নোট তৈরি করবে।

5. **"বন্ধ করুন" বাটনে চাপুন:**
   - মিটিং শেষে স্টপ বাটনে ক্লিক করলে সমস্ত স্ট্রিম ও কানেকশন ক্লিনলি রিলিজ হয়ে যাবে।

## 🛡 এজ কেস ও স্থিতিস্থাপকতা (Resilience)

- **ব্যাকএন্ড বন্ধ থাকলে:** স্টার্ট বাটনে চাপলে Fail-fast চেকে ইনস্ট্যান্ট পরিষ্কার বাংলায় নোটিফিকেশন দেয়।
- **মাইক্রোফোন অনুমতি:** মাইক্রোফোন ব্লক থাকলেও মিটিং ট্যাবের অডিও নির্বিঘ্নে চলবে এবং সাইড প্যানেলে ওয়্যার্নিং সহ ১-ক্লিক পারমিশন বাটন থাকবে।
- **ট্যাব ক্লোজ হলে:** মিটিং ট্যাব বন্ধ বা রিফ্রেশ হলে সেশন স্বয়ংক্রিয়ভাবে ক্লিন টিয়ারডাউন হবে।
- **নেটওয়ার্ক ড্রপ:** ব্যাকএন্ড সাময়িক রিস্টার্ট বা ড্রপ হলে এক্সটেনশন অটো-রিকানেক্ট (Exponential backoff) করবে।
